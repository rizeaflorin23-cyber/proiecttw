Dealership Auto Web App

Descriere :
Dealership Auto este o aplicație web SPA pentru gestionarea unui parc
auto, realizată conform cerințelor proiectului la Tehnologii Web.
Aplicația include un front-end modern și un back-end RESTful
care gestionează date într-o bază relațională folosind un ORM.

Tehnologii utilizate :
Front-end
-React.js / Angular / Vue
-HTML5, CSS3, JavaScript (ES6+)
-Axios / Fetch
-Router + state management
Back-end
Node.js + Express
ORM: Sequelize / Prisma / TypeORM
PostgreSQL / MySQL
Validări cu Joi / Zod

Structura bazei de date
Tabel: Cars
  Câmp          Tip       Descriere
  ------------- --------- ------------------
  id            INT, PK   identificator
  make          VARCHAR   marca
  model         VARCHAR   model
  year          INT       anul fabricației
  price         DECIMAL   preț
  mileage       INT       kilometri
  fuel          VARCHAR   combustibil
  description   TEXT      detalii
  imageUrl      VARCHAR   poză
  createdAt     DATE      generat automat
  updatedAt     DATE      generat automat
